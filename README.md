# OpenSDK Samples

Sample applications for the Hanwha Vision OpenSDK.
Each sample shows how to build an application that runs on Hanwha Vision cameras, using the OpenSDK build environment distributed as a Docker image.
The samples cover camera events, media and metadata handling, SUNAPI requests, NPU APIs, web services, and Python components.

## Prerequisites

- Docker with Docker Compose
- A Hanwha Vision camera that supports OpenSDK applications <!-- TODO: link to the supported devices list -->
- The OpenSDK Docker image, available locally as `opensdk:<version>`

### Get the OpenSDK image

The samples build with `opensdk:<version>`. Get the image in either of these ways.

**From Docker Hub.** The image is published as [hanwhavisionlabs/opensdk](https://hub.docker.com/r/hanwhavisionlabs/opensdk). Pull the version you need and tag it with the name the samples use:

```bash
docker pull hanwhavisionlabs/opensdk:<version>
docker tag hanwhavisionlabs/opensdk:<version> opensdk:<version>
```

**From the distributed image file.** Loading `opensdk-<version>.tar.gz` creates `opensdk:<version>` directly:

```bash
docker load -i opensdk-<version>.tar.gz
```

Check the image with `docker images opensdk`.

Each release has two tags for the same image: `<version>` (for example, `26.10.26`) and `<version>_<soc>`, which names the SoC family the image supports (for example, `26.10.26_wn9`). Use the `<version>` tag as `SDK_VER` when you build a sample. There is no `latest` tag.

## Getting Started

1. Clone this repository.

```bash
git clone https://github.com/hanwhavisionlabs/opensdk-samples.git
cd opensdk-samples
```

2. Build and package a sample from its directory, not from the repository root. Set `SDK_VER` to the tag of the loaded OpenSDK image and `SOC` to the target SoC of your camera.

```bash
cd <sample-directory>
APP_NAME=<sample-directory> SDK_VER=<version> SOC=<soc> docker compose up
docker compose down --remove-orphans
```

The compose file runs the OpenSDK toolchain in the `opensdk:${SDK_VER}` container, configures the CMake project with `SOC`, runs `make clean`, `make`, and `make install`, and packages the result with `opensdk_packager`. A successful build produces `<sample-directory>.cap` in the sample directory.

3. Install the `.cap` file from the **Open Platform** page of the camera web viewer, start the application, and open it with **Go App**.

Packaging needs a signing key and certificate in `/opt/opensdk/signature` of the OpenSDK image. See the OpenSDK Programming Guide for how to obtain and add them.
