= webservice_sample

This sample application is designed to test request webservice.

=== Requirements

* Hanwha Vision Open Platform 26.12.01 or higher

=== I.  Overview
* Purpose: Custom webservice endpoints provide a flexible way to register and handle custom HTTP endpoints on the device.

=== II. Architecture
This sample application demonstrates how OpenSDK enables external HTTP requests to be integrated into an application through a component-based, event-driven architecture. It shows not only how endpoints are registered but also how they are used, processed, and responded to.
When the application starts, custom HTTP endpoints are registered with OpenSDK. The purposes are:

* Allow the device to receive HTTP requests from external clients (e.g., an external system that requests an image over SOAP/XML).

* Forward incoming requests to the application through the AppDispatcher for event-driven processing.

* Enable the application to execute business logic and generate responses (e.g., SOAP/XML with base64-encoded image data).

* Require HTTP Digest authentication for the custom endpoint (CustomSetting(true, netsvc::IHttpdService::AuthMethod::kDigest)).

=== III. Implementation steps
. Setting up CustomSetting() for authentication configuration
+
[source,xml]
----
attach->CustomSetting(true, netsvc::IHttpdService::AuthMethod::kDigest);
----
+
. Registering custom URIs (outside the default /opensdk/<AppID>/ path)
+
[source,xml]
----
 const uri = `${window.location.protocol}//${window.location.hostname}:${window.location.port}/SampleWebService/GetImage`;
----
+
[source,xml]
----
auto* attach = new ("OpenAPIRegistrar") IAppDispatcher::OpenAPIRegistrar(String("/SampleWebService/GetImage"), GetInstanceName(), "POST");
SendNoReplyEvent("AppDispatcher", (int32_t)IAppDispatcher::EEventType::eRegisterCommand, 0, attach);
----
+
. Handling HTTP requests and generating responses
+
Handle HTTP request event: 
[source,xml]
----
case (int32_t)IAppDispatcher::EEventType::eHttpRequest: {
  result = ParseHttpEvent(event);
  break;
}
----
ParseHttpEvent: 
[source,xml]
----
bool WebServiceComponent::ParseHttpEvent(Event* event) {
  if (event->IsReply()) {
    return true;
  }

  auto oas = static_cast<OpenAppSerializable*>(event->GetBaseObjectArgument());
  auto path_info = oas->GetFCGXParam("PATH_INFO");
  // Check if the client is calling the GetImage service endpoint
  if (path_info == "/SampleWebService/GetImage") {
    if (oas->GetMethod() == "POST") {
      oas->SetStatusCode(200); //request OK
      oas->SetResponseBody(requestHttpService()); //requestHttpService() return xml body response
      oas->AddResponseHeader("Content-type", "text/xml; charset=utf-8"); //Add the HTTP Content-Type header to the response that the server returns to the client.
      return true;
    }
    oas->SetStatusCode(400); //error
    oas->SetResponseBody("requested path is not supported");
    return false;
  }
}
----

+
. Lifecycle considerations (when to register endpoints)
* To obtain the AppID, join the AppInfo group as follows in AppDispatcher_manifest_instance_0.json:
+
[source,xml]
----
{  
  "Source": 2009002,  
  "GroupName": "AppInfo"  
}
----



=== IV. Testing

[arabic]
. Open the camera’s web viewer, go to [Settings]>[Open Platform], and click [Start] to start the application.
. Click [Go App] in the camera web viewer.
. Click [Send Event WebService]
== Result
- **When clicking [Send Event Webservice] in the UI:**
  * The application sends an HTTP POST request to the API: `/SampleWebService/GetImage`.
  * If the request is successful (**HTTP 200 OK**), the XML response is displayed on the UI next to the button.
- **Or use in terminal:**
  curl --digest -u <user>:<password> -X POST "http://<device_ip>/SampleWebService/GetImage"

- **Notes:**
  * `<device_ip>`: IP address of the device on which the application is running.
  * `<user>`, `<password>`: a camera account. The endpoint requires HTTP Digest authentication.

- **Expected response if the request succeeds (HTTP 200 OK):**
  The camera returns a valid XML message. 
  . Example:

[source,xml]
----
<?xml version="1.0" encoding="UTF-8"?>
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/" xmlns:smp="urn:example:opensdk:webservice-sample">
  <soapenv:Body>
    <smp:GetImageResponse>
      <smp:Base64String>/9j/4AAQSkZJRgABAQAAAQABAAD/2wBDAAgGBgc</smp:Base64String>
    </smp:GetImageResponse>
  </soapenv:Body>
</soapenv:Envelope>
----
