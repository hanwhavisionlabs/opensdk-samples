Camera I/O

Display Image

1. Start Server

2. Request Image

3. Display Image

Instruction

  1. Open Setup > Network > HTTPS in the camera web viewer and set HTTP to On.
  2. Open Setup > Open Platform, start the application, and click Go App.
  3. Open the app web page using its http:// URL. Do not use the app page's https:// URL.
  4. Click Start Server.
  5. Click Request to connect to the native TCP service.
  6. Click Stop Server after the image is displayed.

Result

A JPEG image is displayed below the Request button. Start and Stop return an accepted status.

SDCard Output Event

Formatting an SD card is destructive. This test requires SDCard permission and physical media.

1. Get SD Card Status

2. Start SD Card

3. Stop SD Card

4. Format SD Card

5. Set Exclusive Mode

6. Get Exclusive Mode Status

Instruction

  1. Install the application with SDCard permission.
  2. Use slot 0 or slot 1 according to the camera hardware.
  3. Click Send, then click the corresponding Get Result button.
  4. Do not format a card containing required data.

Result

Status, path, stop, format, and exclusive-mode replies are kept in the component and displayed in the original Send/Get flow.
